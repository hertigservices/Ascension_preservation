Server import behavior

The SQL contains typed reward fields, complete source records, item identity evidence, and callable apply/rollback procedures. Load it into a disposable world copy using MySQL 8.4, with its worldserver stopped. Loading stages the data; an explicit dry-run/apply call selects one mode-specific source view.

The importer can correct existing quest rewards for fixed/choice items, money, max-level money, XP difficulty, honor, arena points and talent points. It checks quest/item names, source ambiguity, numeric bounds and conversion issues. It reports missing quest templates or currency items instead of inventing definitions. It never silently clamps a 100,000-unit reward into a 65,535-unit column.

Spells, titles, reputation and honor multipliers remain in the export; differences require core/DBC review before server application. Item currency rewards do not, by themselves, recreate currency vendors, account balances or scripted behavior. Rollback restores world reward definitions, not earned rewards or character progress.
